### Machine Learning Algorithms

#### Machine Learning algorithms can widely be classified into two types; `Regression` and `Classification`. These types of algorithms contain multiple other algorithms. Let's get a brief introduction to both these types of algorithms and their subtypes as well.

##### 1) Regression:
- Regression is a type of supervised learning that is used to predict a continuous numerical value based on one or more `features (Independent Variables)`. These types of algirithms are used to predict numerical values such as salaries and house prices. Some common regression algorithms are:

1) Linear Regression
2) Logistic Regression
3) Polynomial Regression
4) Ridge Regression
5) Lasso Regression
