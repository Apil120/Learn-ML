# Learn-ML

Learn-ML is a passion project created with the intention of helping people get into ML from just the basics of python.

## Project Structure

```
Learn-ML/
├── LinearRegression/          # Linear Regression implementation and examples
├── LogisticRegression/        # Logistic Regression implementation and examples
├── machinelearning.ipynb      # Main Jupyter Notebook with ML tutorials
├── requirements.txt           # Project dependencies
├── .gitignore                 # Git ignore rules
└── README.md                  # This file
```

## Dependencies

This project uses the following Python libraries:

- **numpy** - Numerical computing and array operations
- **pandas** - Data manipulation and analysis
- **matplotlib** - Data visualization and plotting

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Apil120/Learn-ML.git
   cd Learn-ML
   ```

2. Create a virtual environment:
   ```bash
   python -m venv .venv
   ```

3. Activate the virtual environment:
   - **Windows:**
     ```bash
     .venv\Scripts\activate
     ```
   - **macOS/Linux:**
     ```bash
     source .venv/bin/activate
     ```

4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Getting Started

- Start with `machinelearning.ipynb` for an introduction to machine learning concepts
- Explore the `LinearRegression/` folder for linear regression examples
- Check the `LogisticRegression/` folder for classification examples
